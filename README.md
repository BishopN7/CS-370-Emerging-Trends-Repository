# CS-370-Emerging-Trends-Repository
The goal of this repository is to hone in on my learning and experience within AI trends. 

**Briefly explain the work that you did on this project: What code were you given? What code did you create yourself?**
The code that I started off with was starter code within the Jupyter notebook. It was essentially a starter kit to get familiar with how modularity works. The goal of this starter code was to simulate a treasure hunter game by manipulating some of the values to get the pirate (the agent) to the treasure. This was faced with a challenge of navigating a complex maze to accomplish the given-objective. The first file 'TreasureMaze.py' was responsible for tracking game boundaries, acted as an environment matrix, and calculated specific feedback penalties. The 'GameExperience.py' file was involved in handling memory tracking to allow for the storage and retrieval of transition sequences. Lastly, the 'TreasureHuntGame_starterCode.ipynb' file laid out the foundation for the deep neural network, along with optimization for movement across the maze seamlessly.
